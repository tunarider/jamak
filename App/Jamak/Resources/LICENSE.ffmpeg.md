# FFmpeg

Jamak은 MKV를 mp4로 바꾸고 자막을 영상에 넣을 때 FFmpeg(https://ffmpeg.org)를 씁니다.
앱 안의 `Contents/Helpers/ffmpeg`는 FFmpeg 7.1.5를 GNU Lesser General Public License
버전 2.1 이상(LGPL v2.1+)으로 빌드한 별도 실행 파일입니다. GPL 구성요소와 nonfree 구성요소는 넣지 않았습니다.

- 소스: https://ffmpeg.org/releases/ffmpeg-7.1.5.tar.xz
  (sha256 de668509caf9e35e3cd162473441fdb29538c6d96ed080292b3cf9e6fc5d558f)
- 빌드 방법과 configure 옵션: 저장소의 `scripts/build-ffmpeg.sh`
- 라이선스 전문: https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html
