# Jamak UI 개편 설계

- 작성일: 2026-11-07
- 상태: 시안 승인됨 (사용자: "이 방향으로 진행")
- 시안: [mockups/redesign.html](mockups/redesign.html) — 편집·검토, 생성 중, 프로젝트 목록, 설정 네 화면

표기: **[결정]** 은 사용자가 정한 것, **[제안]** 은 설계자가 정한 것(시안에 담겨 승인됨), **[빌더]** 는 구현자 재량.

## 1. 왜 하는가

사용자 평가: "누가 봐도 무료 오픈소스 프로그램 같다", "버튼 형태와 배치가 촌스럽다", "전체가 흰색인데 프레임 패널만 검은색이라 색이 너무 상반된다".
영상 편집 프로그램을 써 본 적은 없지만 촌스러움은 보인다고 했고, 방향은 설계자 추천에 맡겼다. **[결정]**

지금 구조의 원인:
- 툴바에 글자 버튼 7개가 한 줄로 나열됨(프로젝트 목록, 전체 자막 생성, 교정, 번역, 작품 노트, 영상 열기, 재생, 내보내기).
- 영상 → 자막셋 바 → 구간 바 → 타임라인 → 편집 패널이 세로로만 쌓임. 진행 막대가 끼어들면 전체가 밀린다.
- 시스템 밝은 모드 위에 영상(검정)과 타임라인(이미 어두움)만 어둡다.

**목표:** 전문 편집 프로그램처럼 보이고 동작하는 한 덩어리의 어두운 작업 화면. 기능 흐름(생성 → 교정 → 번역 → 검토 → 내보내기)이 화면 구조에서 바로 읽힌다.

**비목표:** 밝은 테마, 사용자 테마 설정, 창 배치 저장·작업 공간 전환, 아이콘 세트 직접 그리기(SF Symbols 사용).

**반목표:** 기존 기능이 사라지거나 단축키가 바뀜. 개편 때문에 긴 작업 중 UI가 버벅임.

## 2. 시각 체계 [제안]

- 앱 전체를 어두운 외관으로 고정한다(`NSApp.appearance = .darkAqua`). 설정 창 포함.
- 색 토큰 (시안의 CSS 변수와 같은 값):

| 토큰 | 값 | 쓰임 |
|---|---|---|
| bg0 | #121316 | 창 맨 바깥, 영상 영역, 상태 표시줄, 제목 막대 |
| bg1 | #191A1E | 사이드바, 인스펙터, 타임라인 패널 |
| bg2 | #202227 | 입력란, 카드, 버튼 바탕 |
| bg3 | #282A30 | 선택된 행, 눌린 세그먼트 |
| line / line2 | #2C2F35 / #383B42 | 구분선 / 테두리 |
| text / text2 / text3 | #E9E7E2 / #A3A5AC / #6E717A | 본문 / 보조 / 흐림 |
| accent | #F2CC4E (글자 #1A1608) | 재생 헤드, 선택 조각 테두리, 선택 구간, 주 버튼, 현재 탭 밑줄 |
| screen / speech / sound | #9B7BE6 / #4F8EF0 / #E3874F | 레인·조각 색 |
| suspect / fixed | #EF5A55 / #3FB68B | 의심 "!" / 고침 "✓" |

- 강조색(노랑)은 위 쓰임에만 쓴다. 다른 곳에 장식으로 쓰지 않는다.
- 글꼴은 시스템 글꼴. 시간 표기는 모두 고정폭 숫자(`.monospacedDigit()`).
- 아이콘은 SF Symbols. 버튼은 아이콘+글자(주요 동작) 또는 아이콘만(도구, 도움말 툴팁 필수).
- 기존 타임라인 색(`TimelineNSView` 팔레트)은 위 토큰으로 맞춘다.

## 3. 편집 화면 구조 [제안]

```
┌ 제목 막대: [목록] 프로젝트 이름·길이·해상도 │ 작업 흐름 레일 │ [작품 노트] | [내보내기] ┐
├ 왼쪽 사이드바 ┬ 영상 ─────────────────────┬ 인스펙터 ────────┤
│ 자막셋 목록    │                            │ [조각] [작품 노트] │
│ 검토할 조각    │ 재생 막대                   │                    │
├──────────────┴──── 타임라인 (창 전체 폭) ───┴──────────────────┤
├ 상태 표시줄 ──────────────────────────────────────────────────┤
```

- 왼쪽·오른쪽·아래 패널은 크기를 끌어서 바꿀 수 있다. 최소·기본 너비는 **[빌더]**(시안: 왼쪽 232, 오른쪽 336, 타임라인 높이 280).
- 창 최소 크기 1100×700 **[빌더: 조정 가능]**.

### 3.1 제목 막대 (창 툴바)
- 왼쪽: "프로젝트 목록" 아이콘 버튼, 프로젝트 이름과 `길이 · 해상도 · fps`.
- 가운데: **작업 흐름 레일** — 이 개편의 대표 요소. 단계 네 개: 받아쓰기 → 분석 → 교정 → 번역.
  - 받아쓰기 단계는 지금의 "전체 자막 생성" 미디어 단계(오디오, 받아쓰기, 소리, 프레임, 화면 글자)를 묶어 표시한다.
  - 상태: 안 함(점선 원), 진행 중(노란 원형 진행), 끝남(초록 체크). 교정 단계에는 의심 수 배지.
  - 번역 단계: 만들어진 번역 언어 알약(끝남=초록), 그리고 "+ 언어".
  - **누르면 [제안]:**
    - 받아쓰기·분석·교정: 메뉴가 뜬다. "전체 자막 생성"(이어서 하기/처음부터 다시) · "분석 다시 하기" · "교정"(제안만). 지금 툴바·메뉴에 있는 같은 명령을 부른다.
    - 언어 알약: 그 언어 자막셋으로 전환(저장 확인 흐름).
    - "+ 언어": 번역 대상 언어 메뉴(지금 "번역" 메뉴와 같은 목록과 조건).
  - 비활성 조건과 도움말 문구는 지금 버튼과 같다(LLM 미설정 등).
- 오른쪽: "작품 노트"(인스펙터를 작품 노트 탭으로 열기), 구분선, "내보내기"(주 버튼, 노랑).
- 지금 툴바의 "영상 열기"는 메뉴(파일)와 프로젝트 목록으로 옮긴다. "재생/일시정지"는 재생 막대로 옮긴다.

### 3.2 왼쪽 사이드바
- **자막셋**: 언어마다 한 행 — 언어 코드 배지, 언어 이름, "원문/번역 · N조각", 의심 수 배지. 현재 자막셋은 강조(왼쪽 노란 막대). 행을 누르면 전환(기존 저장 확인 흐름). 머리의 "+"는 srt 가져오기.
  - "원문"은 `state.sourceLanguage`, "번역"은 `state.translations`에 있는 언어. 둘 다 아니면 표시 없음.
  - 잠긴 자막셋은 의심 배지 대신 자물쇠 "잠김".
- **검토할 조각**: 현재 자막셋의 표시(의심·고침) 목록, 타임라인 순서. 필터 칩: 전체 / 의심 N / 고침 N. 행: 표시 종류, 시작 시간, 본문 한 줄, 이유 한 줄. 누르면 선택하고 그 위치로 이동(⌘G와 같은 동작).
- 생성·LLM 작업 중에는 검토 목록 대신(또는 그 위에) **진행 기록**을 보인다: 단계 이름, 끝난 단계는 걸린 시간, 진행 중 단계는 "구간 n/m" 또는 %. 아래에 "취소하거나 앱을 꺼도 끝난 구간은 저장돼 있어요. 다음에 이어서 해요."

### 3.3 영상과 재생 막대
- 영상 영역 배경 bg0, 영상은 비율 유지. 안전 영역 점선은 넣지 않아도 된다 **[빌더]**.
- 자막 겹쳐 보기: 지금처럼 재생 위치의 조각, 화면 조각은 위쪽.
- **원문·번역 겹쳐 보기 (새 기능):** 재생 막대 오른쪽 세그먼트 `<현재 언어> / <짝 언어> / 둘 다`.
  - 짝 언어: 현재가 번역이면 그 원문(`translations[cur].sourceLanguage`), 현재가 원문이면 가장 최근 번역 하나 **[빌더: 고르는 규칙]**. 짝이 없으면 세그먼트를 숨긴다.
  - "둘 다": 아래쪽에 두 줄 — 현재 언어 위, 짝 언어 아래(작게, 흐리게). 짝 언어 조각은 저장된 자막셋에서 시간으로 찾는다(편집 불가, 보기만).
- 재생 막대: 왼쪽 큰 시간 표기 `현재 / 전체`, 가운데 [이전 조각][1초 뒤로][재생/일시정지][1초 앞으로][다음 조각], 오른쪽 겹쳐 보기 세그먼트와 음량.
  - 이전/다음 조각: 현재 자막셋에서 재생 위치 앞뒤의 조각 시작으로 이동 **[제안]**.

### 3.4 인스펙터
- 탭: "조각" / "작품 노트". 작품 노트 탭은 지금 오른쪽 노트 패널의 내용(편집, 자동 저장, LLM 쓰는 중 잠금 문구)을 그대로 옮긴다.
- 조각 탭(선택 없음): 안내 문구 "자막 조각을 선택하면 여기서 문장과 시간을 고칠 수 있어요."
- 조각 탭(선택 있음):
  - 종류 세그먼트(색 점 + 화면/음성/소리)
  - 시작·끝 시간 입력, 오른쪽에 길이(초)
  - 문장 편집란(크게), 아래에 **글자 수와 초당 글자 수(새 기능)**. 초당 글자 수가 기준을 넘으면 경고색. 기준값 **[빌더: 제안 한국어·일본어 12자/초]**. 공백과 문장부호 셈법 **[빌더]**.
  - 검토 카드(표시가 있을 때): 머리(표시 종류, 제목, 출처), 프레임 썸네일 최대 3장(조각 시작·가운데·끝 초, 캐시에 있는 것만, 각 시간 표기), 이유, 제안이 있으면 바뀐 부분 비교(원래 → 제안, 지운 부분 빨강 취소선, 넣은 부분 초록), 버튼.
    - 의심: [제안으로 바꾸기](주 버튼, 제안 있을 때) [그대로 두기]
    - 고침: "원래 문장" 비교 + [원래 문장으로 되돌리기] [그대로 두기]
  - 아래 동작 목록: "이 조각 다시 받아쓰기", "다음 의심 조각 ⌘G".
  - 생성 중(자막셋 잠김): 맨 위에 자물쇠 카드 "자막을 만드는 중이에요 — 끝나면 결과를 한 번에 넣어요. 그동안 원문 자막셋은 보기만 할 수 있어요. 재생과 이동은 그대로 돼요." 아래 입력란은 흐리게, 비활성.
- 비교 표시는 글자 단위 차이 **[빌더: 알고리즘]**.

### 3.5 타임라인
- 위 도구 막대: [선택|구간] 도구 세그먼트, "스냅" 토글, 구간을 고르면 나타나는 **구간 칩**(노란 테두리, 구간 시간 + 다시 받아쓰기 · 화면 글자 찾기 · 이 구간만 번역), 오른쪽 줌 슬라이더(−/+).
  - 지금의 구간 바(RangeBar)는 이 칩으로 흡수한다. 구간 작업의 진행·취소는 상태 표시줄로 간다.
  - 선택/구간 도구 **[제안]**: 선택 도구에서는 지금처럼 눈금자 드래그가 구간 선택. 구간 도구에서는 레인 위 드래그도 구간 선택(조각 이동 대신). 기본은 선택 도구.
  - 스냅: 지금 100ms 스냅의 켜고 끄기(⌥ 일시 해제는 유지).
- 트랙 머리(왼쪽 150px): 색 막대, 레인 이름(화면/음성/소리), 조각 수, 눈 아이콘.
  - **트랙 숨기기(새 기능):** 눈을 누르면 그 레인의 조각을 타임라인과 영상 겹쳐 보기에서 숨긴다. 저장·내보내기에는 영향 없음. 상태는 프로젝트별로 기억하지 않는다 **[제안]**.
  - 잠긴 자막셋이면 눈 대신 자물쇠.
- 레인, 조각, 배지, 겹침 빗금, 재생 헤드(노란 삼각 머리)는 지금 `TimelineNSView` 그리기를 새 색으로 맞춘다. 레인 높이는 패널 높이에 맞춰 늘어난다 **[빌더]**.

### 3.6 상태 표시줄
- 왼쪽: 저장 상태 "● 저장됨"(초록) / "● 저장 안 된 변경"(노랑), 잠금이 있으면 "<언어> 잠김", 선택 요약(예: "선택: 음성 1조각").
- 가운데: 실행 중인 작업 — 단계 이름, "구간 n/m" 또는 %, 진행 막대, [취소]. 지금 GenerationProgressView와 RangeBar의 진행 표시를 대신한다.
- 오른쪽: LLM 설정 요약 "Ollama · <텍스트 모델> · 비전 <비전 모델>", 미설정이면 "LLM 설정 안 됨".

## 4. 프로젝트 목록 [제안]
- 같은 어두운 창. 제목 막대: 앱 이름과 프로젝트 수, 오른쪽 검색 입력과 "영상 열기"(주 버튼).
- 왼쪽: 필터 목록 "최근 프로젝트" / "검토할 곳이 있음" / "이어서 할 작업"(각 개수).
- 본문 위: 끌어다 놓기 영역(아이콘, "영상을 끌어다 놓아 새 프로젝트를 만드세요", "mp4, mov, mkv. MKV는 열 때 mp4로 바꿔요. 원본 영상은 옮기지 않아요.", [파일 고르기]).
- 카드 격자: 포스터(프레임 캐시에서 한 장 — 영상 길이의 10% 지점에 가장 가까운 프레임 **[제안]**; 없으면 그라데이션 자리), 길이, 이름, 언어 알약, 작업 진행 네 칸(받아쓰기·분석·교정·번역: 끝남 초록/진행 노랑/안 함 회색), 상태 한 줄(검토할 조각 N / "<단계> n/m에서 멈춤" / "검토 끝"), 마지막으로 연 때.
  - 영상을 찾을 수 없는 프로젝트는 포스터 위에 "영상을 찾을 수 없어요 · 다시 지정".
  - 카드 우클릭 메뉴: 열기, Finder에서 보기, 삭제(기존 동작) **[빌더: 지금 목록의 메뉴를 옮김]**.
- 목록 정보는 지금처럼 project.json과 파일 이름만으로 만든다(자막 파일을 읽지 않음). 검토 수는 `state.annotations`에서 센다.

## 5. 설정 [제안]
- 탭: 받아쓰기 / LLM / 저장 공간. 받은 모델 지우기와 프레임 캐시 지우기는 "저장 공간"으로 옮긴다.
- LLM 탭: 프로바이더 목록 카드(약칭 배지, 이름, base URL, 연결 상태 "연결됨 · 모델 N개" 또는 "확인 안 함"), [프로바이더 추가] [연결 확인], 역할별 모델(텍스트/비전 선택, 동시 요청 스테퍼), 안내 문구. 동작은 지금과 같다.

## 6. 바뀌지 않는 것
- 모든 기능, 명령, 단축키, 확인 대화상자, 문구(새 위치로 옮기기만 함). 메뉴 막대 명령은 그대로 둔다.
- 데이터 형식, 저장 방식, 파이프라인.

## 7. 빌더 재량
- SwiftUI/AppKit 조합, 패널 분할 구현, 커스텀 버튼 스타일, 레일 구현 방식(툴바 principal item 등).
- 애니메이션은 최소(진행 원 갱신 정도).
- 수치 세부값(여백, 반경, 너비)은 시안을 출발점으로 한다.

## 8. 빌더 점검 뒤 설계자가 정한 것 [제안]

1. **시안의 구속력**: 구조, 색 토큰, 간격·크기의 비율을 맞춘다. 픽셀 단위 일치는 아니다. 다만 macOS 기본 모양 그대로인 버튼·세그먼트·툴바 글자 버튼은 쓰지 않는다. 레일, 카드, 세그먼트, 버튼은 시안처럼 보이게 직접 스타일을 입힌다. 패널 분할은 시스템 분할 뷰를 써도 된다.
2. **상태 표시는 저장된 값에서만 파생한다. 데이터 형식은 바꾸지 않는다.**
   - 레일의 "진행 중"은 지금 이 프로젝트에서 작업이 실제로 돌 때만이다(`GenerationController`의 현재 단계).
   - 그 밖에는 끝남(해당 플래그 모두 참) / 멈춤(일부만 참) / 안 함(모두 거짓) 세 가지다. 받아쓰기 단계 = `audioExtracted`·`transcribed`·`soundsClassified`·프레임 완료·`textRecognized`. 분석 = `analyzed`. 교정 = `corrected`. 번역 언어 알약 = 그 언어의 `TranslationProgress`(완료=초록, 미완료=노란 테두리 "멈춤").
   - 프로젝트 카드의 멈춤 문구는 "<단계>에서 멈춤"이다. 구간 n/m은 저장하지 않으므로 넣지 않는다.
3. **진행 기록**(사이드바)은 이번 실행의 기록만 메모리에 둔다. 단계별 걸린 시간은 `GenerationController`가 잰다. 앱을 끄면 사라진다. 이번 실행 전에 이미 끝난 단계는 "이전에 끝남"으로 표시한다.
4. **인스펙터는 늘 보인다**(분할선을 끌어 접을 수 있음). 제목 막대 "작품 노트"와 기존 노트 명령은 인스펙터의 탭을 "작품 노트"로 바꾼다. 이미 노트 탭이면 "조각" 탭으로 돌아간다. 따로 떨어진 노트 열은 없앤다.
5. **트랙 숨기기**는 그리기, 클릭 판정, 영상 겹쳐 보기에서 그 레인을 뺀다.
   - 검토 목록이나 ⌘G로 숨은 레인의 조각을 고르면 그 레인을 자동으로 다시 보인다.
   - 숨김 상태는 앱 실행 동안 전역이다(자막셋을 바꿔도 유지, 앱을 다시 켜면 모두 보임).
6. **도구 전환**: 선택 도구 ↔ 구간 도구로 바꿔도 조각 선택은 유지한다. 구간을 만든 뒤에도 도구는 그대로다. 구간은 Esc나 빈 곳 클릭으로 해제한다(지금 동작 유지).
7. **검토 목록**은 편집 중인 자막셋의 장부(`annotationBook`, 저장 안 한 변경 포함)에서 만든다.
   - 장부에 있는 표시만 보인다(해결한 것은 장부에서 이미 빠짐). "고침" = `autoFixed`, "의심" = `suspect`.
   - 다른 자막셋 행의 의심 배지는 `state.annotations` 중 그 언어의 `suspect`이면서 `resolved == false`인 수다.
8. **"둘 다" 겹쳐 보기**: 짝 자막셋에서 재생 위치를 포함하는 조각(시작 ≤ t < 끝)을 모두 보인다. 화면 조각은 위쪽, 나머지는 아래쪽이다. 없으면 아무것도 보이지 않는다.
9. **어두운 외관 강제**: 대화상자, 시트, 파일 선택 창도 어둡게 되는 것을 받아들인다. 설정은 SwiftUI `Settings` 장면과 탭 보기를 유지하고 색만 맞춘다(받아쓰기 / LLM / 저장 공간).
10. **프로젝트 목록 필터**는 저장된 값으로 계산한다.
    - "검토할 곳이 있음" = 미해결 의심 표시가 하나 이상
    - "이어서 할 작업" = `generation`이 있고 미완료이거나, 미완료 `TranslationProgress`가 하나 이상
