왼쪽 자막셋 목록은 이제 언어가 아니라 자막셋 이름(기본, 극장 공개판…)이에요. 각 자막셋 밑에 지원 언어가 붙고, 노란 테두리가 기본 언어예요. 영상 아래 오른쪽은 "출력 언어"예요. 한국어를 고르면 한국어로 보이고, 한국어가 빈 조각은 기본 언어(日本語)를 기울임으로 보여요. "전체"는 지원 언어를 모두 겹쳐 보여요. 오른쪽 인스펙터의 조각 탭에는 지원 언어마다 입력 칸이 하나씩 있어요. 빈 칸에는 "이 조각 번역"이 붙어요. 타임라인 조각 위 글자도 출력 언어를 따르고, 빈 곳은 기본 언어로 기울여 보여줘요("KO 빔" 표시). AI 기능은 제목 막대의 작은 묶음(자동 자막 생성 · 교정 · 번역)으로 내려왔어요. 예전의 작업 흐름 레일은 없어져요.
