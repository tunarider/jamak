# 자막셋 구조 개편 설계

- 작성일: 2026-11-07
- 시안: [mockups/subtitle-sets.html](mockups/subtitle-sets.html) (편집 화면, 새 프로젝트, 자막셋 설정·자동 자막 생성·번역 시트)
- 표기: **[결정]** 은 사용자가 정한 것, **[제안]** 은 설계자가 정한 것(검토 대상), **[빌더]** 는 구현자 재량.

## 1. 왜 바꾸는가

**[결정]**
- 이 앱의 핵심은 자막 편집이다. AI는 부가 기능이다. 사용자는 AI 없이 직접 자막을 만들 수도 있다.
- srt는 가져오기와 내보내기 형식일 뿐이다. 앱 데이터에서 뺀다. 앱은 구조화된 형식으로 자막을 보관한다.
- 지금은 "언어 = 자막셋 = srt 파일"이다. 앞으로는 자막셋이 언어와 무관하고, 조각 하나에 여러 언어 문장이 들어간다.

**반목표** **[제안]**: 기존 기능(편집, 타임라인 조작, 검토 표시, AI 생성·교정·번역·검증, 내보내기, 토큰 사용량)이 사라지면 실패다. 기존 기능은 새 구조에 맞춰 옮긴다.

**하지 않는 것**
- 기존 프로젝트 변환 **[결정]**: 사용자가 직접 지운다.
- 한국어·일본어·영어 밖의 언어, 사용자 정의 언어 **[결정]**
- 언어마다 다른 조각 시간 **[제안]**: 이 구조의 결과로 시간과 종류는 조각 단위다.

## 2. 데이터 모델 [결정, 세부는 제안]

```
Project
  설정과 상태(지금 project.json의 것: 영상 위치, 변환본, 작품 노트 위치, 토큰 사용량 등)
  subtitleSets: [SubtitleSet]           // 최소 1개
SubtitleSet
  id, name                              // 처음 것은 "기본"
  languages: [Language]                 // 한국어/일본어/영어 중 1~3개, 순서 있음
  defaultLanguage: Language             // languages 중 하나
  clips: [Clip]
Clip
  id (저장되는 고정 id), start, end (ms), kind (screen/speech/sound)
  texts: [Language: String]             // 비어 있거나 없는 언어 = 빈 칸
Language = ko | ja | en                  // 표시 이름: 한국어 / 일본어 / 영어
```

- **고정 언어** **[결정]**: 한국어(ko), 일본어(ja), 영어(en)만 쓴다. 자막셋마다 이 셋 중 원하는 언어를 추가하고 뺀다. 언어를 추가하면 그 자막셋의 모든 조각에 그 언어 입력 칸이 생긴다(값은 비어 있음).
- **기본 언어** **[결정]**: 출력 언어 칸이 비어 있을 때 대신 보이는 언어다. 자동 자막 생성의 원문 언어이기도 하다 **[제안]**.
- **자막셋** **[결정]**: 최소 1개. 새 프로젝트에 "기본" 자막셋이 생기고 조각은 없다.
- **조각 id가 저장된다** **[제안]**: 검토 표시를 시간·본문으로 다시 붙일 필요가 없다. 표시는 `(자막셋 id, 조각 id, 언어)`에 붙는다.
- **종류 부호**(화면 「」, 소리 [])는 지금처럼 본문에서 빼고 `kind`로 보관한다. srt로 내보낼 때만 붙인다.

## 3. 저장 [제안]

- 프로젝트 폴더: `project.json`(설정·상태), `subtitles.json`(자막셋 전부), `notes.md`, 캐시(`audio.wav`, `frames/`, `work/`), 변환본 `video.mp4`.
- `subtitles.json`은 원자적으로 쓴다(임시 파일에 쓴 뒤 바꾸기). 저장 순서는 subtitles.json 다음 project.json이다.
- `project.json`에는 형식 버전을 둔다(`version: 2`). **버전 2가 아닌 폴더**(예전 프로젝트)는 프로젝트 목록에 "예전 형식이라 열 수 없어요"로 보이고, 열 수 없다. 삭제는 된다.
- 저장 시점과 "저장 안 된 변경" 표시는 지금과 같다(⌘S, 닫을 때와 바꿀 때 확인). 단위는 자막셋 하나가 아니라 프로젝트 전체 자막 데이터다.

## 4. 새 프로젝트 [결정]

1. 영상을 열거나 끌어다 놓는다(MKV 변환은 지금과 같다).
2. "이 영상의 원문 언어"를 한국어·일본어·영어 중에서 고르는 작은 창이 뜬다. 설정의 원문 언어가 정해져 있으면 그것을 미리 고른다.
3. 프로젝트 폴더와 데이터가 만들어진다. "기본" 자막셋 하나가 생기고, 언어는 고른 언어 하나, 기본 언어도 그 언어, 조각은 없다.
4. 편집 화면이 열린다. 타임라인 가운데에 "조각 추가", "자동 자막 생성…", "srt 가져오기…"가 보인다(시안 2).

## 5. 편집 화면 [시안 1, 제안]

- **제목 막대**: 작업 흐름 레일을 없앤다. 가운데에 "AI" 묶음 — [자동 자막 생성] [교정] [번역 ▾]. 오른쪽은 지금처럼 작품 노트, 내보내기.
- **왼쪽 사이드바 · 자막셋**: 자막셋 이름, 조각 수, 언어 알약(기본 언어는 노란 테두리), 의심 수 배지, 설정 버튼(톱니). 누르면 그 자막셋으로 바꾼다(저장 확인 흐름은 지금과 같다). 머리의 "+"는 자막셋 추가(이름 입력, 언어는 지금 자막셋과 같게 시작하되 조각 없이). 행 우클릭: 이름 바꾸기, 복제(조각 포함), 삭제(마지막 하나는 삭제 불가, 확인 후).
- **검토할 조각**: 지금처럼 이 자막셋의 의심·고침 목록. 행에 언어 표시가 붙는다. 필터에 "번역 빔 N"(출력 언어가 비어 있는 조각 수)을 더한다 **[제안]**.
- **영상 겹쳐 보기와 출력 언어** **[결정]**: 재생 막대 오른쪽 세그먼트 `<언어들…> / 전체`. 하나를 고르면 그 언어를 보이고, 빈 조각은 기본 언어로 대신 보인다. "전체"는 자막셋의 언어를 모두 겹쳐 보인다(기본 언어 먼저). 지금의 "원문·번역 겹쳐 보기"는 이 기능으로 대체한다.
- **타임라인**: 지금처럼 한 번에 한 자막셋을 보인다. 조각 위 글자는 출력 언어를 따르고, 대신 보인 기본 언어는 기울임으로 보인다. "전체"일 때는 기본 언어를 보인다.
- **인스펙터 탭**: 조각 / 자막셋 / 작품 노트.
  - **조각 탭**: 종류, 시작·끝·길이, 그리고 언어마다 입력 칸(언어 이름, 기본 언어 별표, 글자 수와 초당 글자 수, 그 언어의 검토 카드). 빈 칸에는 "비어 있어요 · 영상에는 기본 언어로 보여요"와 [이 조각 번역]. 아래에 "이 조각 다시 받아쓰기", "다음 의심 조각".
  - **자막셋 탭**: 자막셋 설정(이름, 언어 목록과 기본 언어, 언어 추가 ▾·삭제)을 인스펙터 안에서 바로 고친다. 시안의 "자막셋 설정" 시트 내용과 같다.
- **조각 추가** 버튼과 더블클릭은 지금과 같다. 새 조각은 모든 언어가 빈 칸이고, 기본 언어 칸에 커서가 간다.

## 6. 언어 추가·삭제 [결정, 세부는 제안]

- "언어 추가 ▾"는 자막셋에 아직 없는 고정 언어만 보인다.
- 언어 삭제: 기본 언어는 삭제할 수 없다(먼저 기본 언어를 바꾼다). 삭제하면 모든 조각에서 그 언어 문장과 그 언어의 검토 표시가 지워진다. 확인을 거치고, 실행 취소할 수 있다.
- 기본 언어 바꾸기: 아무 문장도 바뀌지 않고 대신 보이는 언어만 바뀐다.

## 7. 가져오기와 내보내기 [제안]

- **srt 가져오기**: 대상 자막셋과 언어를 고른다.
  - 자막셋에 조각이 없으면: srt 줄마다 조각을 만들고 그 언어 칸에 넣는다(종류는 부호로 판정).
  - 조각이 있으면: 시간이 겹치는 조각(같은 종류, 겹침이 가장 큰 것)의 그 언어 칸에 넣는다. 짝이 없는 줄은 새 조각으로 만든다. 그 언어에 이미 문장이 있는 조각이 있으면 덮어쓸지 묻는다.
  - 그 언어가 자막셋에 없으면 먼저 추가한다(확인).
- **srt 내보내기**: 자막셋 하나와 언어 하나 이상을 고른다. 언어마다 파일 하나 `영상이름.<언어코드>.srt`. 빈 칸은 기본 언어로 채울지 비울지 고른다(기본: 채움 — 화면 표시와 같게).
- **자막 넣은 영상 내보내기**: 지금과 같다. 트랙 = 자막셋 하나의 언어마다 하나, 언어 태그는 jpn/kor/eng.
- 여러 자막셋을 한 번에 내보내는 것은 하지 않는다.

## 8. AI 기능 [결정: 부가 기능, 세부는 제안]

모두 지금의 파이프라인을 그대로 쓰고, 입력과 출력만 새 구조에 맞춘다.

- **자동 자막 생성** (자막셋 단위, 시안 3의 시트)
  - 만들 언어 = 자막셋의 기본 언어(바꿀 수 있다 — 고른 언어가 자막셋에 없으면 추가). 받아쓰기, 소리, 화면 글자, 분석과 교정을 체크로 고른다.
  - 이미 조각이 있으면: "모두 지우고 새로 만들기"(다른 언어 번역도 함께 사라짐을 알림) 또는 "조각이 없는 구간만 채우기".
  - 진행·재개·취소는 지금과 같다. 진행 상태는 자막셋마다 저장한다.
- **교정**: 지금 자막셋의 한 언어(기본: 기본 언어)를 교정해 제안만 단다(재실행 정책 그대로). 자동 자막 생성 안의 교정은 지금처럼 자동 적용한다.
- **번역** (시안 3의 시트): 범위(자막셋 전체 / 선택한 조각 / 고른 구간), 원문 언어 → 번역할 언어(그 자막셋의 언어 중, 없으면 추가), 빈 칸만 / 모두 다시, 번역 검토 여부.
  - 결과는 같은 조각의 번역 언어 칸에 쓴다. 시간을 복사하는 일이 없어져서 짝짓기와 "원본 자막셋 시간에 맞추기"는 사라진다.
  - "모두 다시"로 바뀐 문장에는 "고침" 표시와 원래 문장이 남는다.
  - 인스펙터의 "이 조각 번역"은 범위가 조각 하나인 같은 동작이다(원문 = 기본 언어, 대상 = 그 칸).
- **이 구간 다시 받아쓰기 / 화면 글자 찾기 / 이 조각 다시 받아쓰기**: 기본 언어 칸에 쓴다. 조각을 새로 만들면 다른 언어 칸은 비어 있다.
- **작품 노트**: 지금과 같다. 번역 용어집 섹션은 언어 이름(`## 번역: 한국어`)으로 둔다.
- **토큰 사용량**: 지금과 같다(프로젝트 누적).

## 9. 없어지는 것

- 언어별 srt 파일 저장, `lastOpenedLanguage`, 언어별 `translations` 진행, 언어 단위 자막셋 목록과 언어 전환.
- 작업 흐름 레일(제목 막대 가운데) — AI 묶음으로 대체.
- 원문·번역 짝짓기, "원본 자막셋 시간에 맞추기", 시간 겹침으로 검토 표시 다시 붙이기.

## 10. 빌더 재량

- JSON 세부 키 이름, 저장 형식 버전 처리.
- 편집기(실행 취소) 구조: 지금의 `SubtitleSetEditor`를 새 자막셋 모델로 바꾸거나 새로 만든다. 실행 취소는 프로젝트 자막 데이터 전체 단위여도 되고 자막셋 단위여도 된다 — 단, 언어 추가·삭제, 자막셋 추가·삭제, 문장 편집, 조각 이동이 모두 실행 취소되어야 한다.
- 파이프라인 입력·출력 어댑터의 위치.

## 11. 빌더 점검 뒤 설계자가 정한 것 [제안]

1. **파이프라인은 어댑터로 잇는다.** 지금의 한 언어용 자막 타입(`SubtitleSet`/`SubtitleClip`, `text` 하나)은 내부 "언어 보기"로 남긴다.
   - 새 자막셋에서 한 언어를 뽑아(조각 id 유지, 빈 칸은 빈 문자열 또는 제외 — 파이프라인별로 정함) 파이프라인에 넣는다.
   - 결과는 같은 id의 조각, 같은 언어 칸에 다시 쓴다.
   - 타임라인 그리기도 출력 언어로 뽑은 보기를 쓴다.
   - 새 모델 타입 이름은 빌더 재량이다. 단, 사용자에게 보이는 말은 "자막셋", "조각", "언어"다.
2. **검토 표시**는 `(자막셋 id, 조각 id, 언어)`에 붙는다.
   - 시간·본문으로 다시 붙이는 처리(`AnnotationMatcher`, 스냅숏의 시간·본문 갱신)는 없앤다.
   - 문장을 고쳐도 표시는 사용자가 "제안으로 바꾸기", "그대로 두기", "되돌리기"를 할 때까지 남는다.
   - 같은 칸에 새 결과(교정, "모두 다시 번역")가 오면 같은 종류의 이전 표시를 바꾼다(지금 규칙과 같다).
   - 조각을 지우거나 언어를 지우면 그 표시도 지운다. 실행 취소하면 함께 돌아온다.
3. **조각이 가진 것**은 시간, 종류, 언어별 문장뿐이다. "고침"의 원래 문장은 지금처럼 표시(annotation)에 둔다.
4. **자동 자막 생성**
   - "조각이 없는 구간만 채우기"는 언어와 상관없이 어떤 조각과도 겹치지 않는 구간만 채운다.
   - 만들 언어가 기본 언어와 다르면 결과는 그 언어 칸에 쓰고, 새 조각의 다른 칸은 비어 있다.
   - "모두 지우고 새로 만들기"는 그 자막셋의 조각을 모두 바꾼다.
5. **실행 취소와 저장은 프로젝트 단위다.** 자막 데이터 전체(모든 자막셋)를 하나의 편집기가 맡는다. 그래서 자막셋 추가·삭제·복제, 언어 추가·삭제, 기본 언어 바꾸기, 문장 편집, 조각 이동이 모두 같은 실행 취소 기록에 들어간다. 자막셋을 바꿔도 기록은 유지된다.
6. **srt 가져오기 짝짓기**: 같은 종류의 조각 중 겹침이 가장 큰 것을 고르고, 같으면 먼저 시작하는 것을 고른다. 조각 하나에는 한 줄만 들어간다.
7. **마지막으로 연 자막셋**은 `project.json`에 `lastOpenedSetID`로 저장한다. 없거나 지워졌으면 첫 자막셋을 연다. 출력 언어도 자막셋마다 기억한다(같은 파일, `outputLanguage` — 없으면 기본 언어).
8. **진행 상태**: 자동 자막 생성 진행은 `project.json`에 자막셋 id별로(`generation: [자막셋 id: …]`), 번역 진행은 `(자막셋 id, 대상 언어)`별로 둔다. 저장 순서는 subtitles.json 다음 project.json이다(지금과 같다). 도중에 비정상 종료되면 진행 기록이 한 단계 뒤처질 뿐 자막은 남는다.
